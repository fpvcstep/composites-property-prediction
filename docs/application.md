# Учебное приложение прогнозирования

Streamlit-приложение выводит два прямых прогноза: модуль упругости при растяжении в ГПа и прочность при растяжении в МПа. Пользователь задаёт 11 признаков; угол нашивки принимает только подтверждённые в наборе значения 0 или 90 градусов. Для признаков, у которых исходная схема не сообщает единицу измерения, интерфейс прямо это указывает.

## Артефакты моделей

Приложение не содержит фиктивных моделей. После этапа обучения в каталоге `models` должны находиться `model_manifest.json` со `schema_version=1` и указанные в нём joblib-артефакты. Каждый артефакт является полностью обученным sklearn-совместимым pipeline и принимает `pandas.DataFrame` с 11 признаками в порядке из manifest. При отсутствии или повреждении manifest/артефакта интерфейс показывает инструкцию вместо аварийного завершения.

Для локального запуска после появления обученных моделей:

```text
streamlit run app/streamlit_app.py
```

Переменная окружения `COMPOSITES_MODELS_DIR` позволяет указать другой каталог артефактов; она используется тестами только с временным каталогом pytest.

## Интерпретация результата

Начальные значения полей — медианы обучающих признаков из manifest. Это только значения по умолчанию для формы, а не измерения нового образца: для прогноза их нужно заменить фактическими характеристиками исследуемого материала. Выход за сохранённые минимумы и максимумы сопровождается предупреждением об экстраполяции, но не блокируется искусственной физической границей. Если по кросс-валидации выбрана baseline-модель, интерфейс сообщает, что её прогноз постоянный и более сложная модель не показала преимущества. Доступные RMSE, MAE и R² отложенного теста показываются как общая характеристика модели; они не представляются как неопределённость отдельного прогноза.

Результат предназначен для учебной демонстрации на ограниченном наборе данных. Он не заменяет лабораторные испытания и не подтверждает применимость к новым материалам, партиям или производственным режимам.
