# Протокол обучения и выбора моделей

## Область текущего этапа

Выбор выполняется только на 716 строках train из `data/splits.json`. Десять сохранённых KFold-разбиений переводятся из исходных `source_index` в позиционные индексы непосредственно перед запуском scikit-learn. Отложенные 307 строк не используются для подбора, сравнения, анализа распределений или расчёта метрик этого этапа.

Основная метрика выбора — средний RMSE по 10 validation-фолдам в исходных единицах цели. Дополнительно сохраняются MAE, R², train-CV ошибки, стандартное отклонение и время fit. Для SVR и MLP цель стандартизуется внутри `TransformedTargetRegressor`; `predict` выполняет обратное преобразование, поэтому scorer получает исходные единицы.

## Модели прямых задач

Для каждой из двух целей используется одинаковый набор из 11 признаков. Обе конечные характеристики исключены из X.

| Семейство | Зафиксированная сетка |
|---|---|
| Dummy baseline | среднее train-фолда |
| Ridge | `alpha`: 0.01, 0.1, 1, 10, 100 |
| Random Forest | четыре сочетания: `(n_estimators, max_depth, min_samples_leaf)` = (200, None, 1), (150, None, 3), (200, 10, 1), (150, 10, 3) |
| Gradient Boosting | четыре сочетания: `(learning_rate, max_depth)` = (0.03, 2), (0.03, 3), (0.1, 2), (0.1, 3); `n_estimators=150` |
| SVR RBF | `C`: 0.3, 1, 3; `epsilon`: 0.05, 0.1; `gamma=scale`; параметры относятся к стандартизованной цели |

Для Ridge, Random Forest, Gradient Boosting и SVR сравниваются два варианта:

- `raw` — без удаления строк;
- `iqr_filtered` — границы 1,5 IQR оцениваются только по X fit-фолда, угол исключён, X и y фильтруются синхронно, predict не удаляет строки.

Внутри каждого семейства выбирается вариант и набор параметров с минимальным средним CV RMSE. Общий выбор сравнивает baseline и четыре победителя семейств. При точном равенстве действует порядок: baseline, Ridge, Random Forest, Gradient Boosting, SVR; внутри семейства `raw` предшествует `iqr_filtered`, затем используется лексикографический порядок JSON параметров.

Baseline имеет право стать итоговой моделью, если его средний CV RMSE минимален. Для воспроизводимости сохраняются baseline и победители всех четырёх классических семейств каждой прямой задачи: Ridge, Random Forest, Gradient Boosting и SVR. Это не означает, что они превосходят baseline.

## Предобработка

В каждый pipeline входят строгая проверка конечных числовых значений и бинарное преобразование подтверждённого на train угла 0°/90° в 0/1. StandardScaler применяется к X для Ridge и SVR; деревья получают исходный масштаб. Imputer и производные признаки не используются.

Масштабирование X и y, а также IQR-границы обучаются заново внутри каждого CV-фолда. При финальном train-only refit исходный `source_index` хранится в `DataFrame.index`, поэтому журнал IQR содержит идентификаторы исходных наблюдений, а не позиции строк.

## Вычислительный режим и фиксация результата

`GridSearchCV` использует `n_jobs=2`; Random Forest — `n_jobs=1`; все случайные компоненты основного выбора получают seed 42. Полные результаты каждой точки сетки сохраняются в `reports/modeling/cv_results.csv`, победители семейств — в `cv_summary.csv`.

Выбор фиксируется в `model_selection.json` с признаком `frozen_before_test=true`, SHA-256 split-манифеста, параметрами и хешами артефактов. `models/model_manifest.json` на этом этапе не создаётся: его обязательные test-метрики могут быть заполнены только после отдельного S09.

## Ограничение семантики отвердителя

В поле `Количество отвердителя, м.%` встречаются train-значения выше 100. Если это массовая доля готовой смеси, такие значения физически невозможны. Однако база процентов и семантика поля не задокументированы, поэтому значения не удаляются и не объявляются ошибками или синтетическими данными. Точное число и диапазон фиксируются после запуска в `training_metadata.json`.

## Результаты train-only выбора

| Задача | Выбранный вариант | CV RMSE, среднее ± std | Baseline CV RMSE |
|---|---|---:|---:|
| Модуль упругости при растяжении | DummyRegressor(mean), raw | 3,087 ± 0,257 ГПа | 3,087 ГПа |
| Прочность при растяжении | Gradient Boosting, raw | 490,209 ± 23,852 МПа | 490,500 МПа |

Для модуля ни одно классическое семейство не улучшило baseline по среднему CV RMSE. Для прочности преимущество Gradient Boosting над baseline составляет около 0,29 МПа, что мало относительно межфолдового разброса; результат не подтверждает устойчивого практического превосходства.

На train 468 из 716 значений количества отвердителя превышают 100; диапазон — от 17,740 до 198,953. Они сохранены из-за неизвестной базы процентов. Отложенный test при этих выводах не использовался.
