# Сценарий демонстрации

Цель демонстрации — показать воспроизводимый запуск и честное поведение приложения. Не использовать случайные или придуманные «реальные» характеристики материала.

## Подготовка до защиты

1. Из корня проекта собрать образ:

   ```powershell
   docker build -t composites-thesis:local .
   ```

2. Запустить тесты без кэшей:

   ```powershell
   docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python -m pytest -q -p no:cacheprovider
   ```

3. Убедиться, что существуют `models/model_manifest.json` и два joblib-артефакта прямых задач, а test-метрики совпадают с `reports/evaluation/metrics.csv`.
4. Полностью выполнить `notebooks/research.ipynb` через проверенную команду nbclient из README.
5. Сохранить локально страницу приложения открытой, но перед выступлением перезапустить контейнер чистой командой ниже.

## Запуск приложения

```powershell
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -p 127.0.0.1:8501:8501 -v "${PWD}:/workspace:ro" -w /workspace composites-thesis:local streamlit run app/streamlit_app.py --server.address=0.0.0.0 --browser.gatherUsageStats=false
```

Открыть <http://localhost:8501>.

## Демонстрация за 60–90 секунд

1. Показать 11 входов. Сказать: «Это признаки двух прямых моделей; угол допускает только 0° или 90°».
2. Обратить внимание на поля без подтверждённых единиц. Сказать: «Неизвестные единицы не были придуманы».
3. Пояснить значения по умолчанию: «Это медианы train для удобства формы, а не измеренный новый образец».
4. Нажать «Прогноз». Показать два результата: модуль в ГПа и прочность в МПа.
5. Для модуля показать сообщение baseline: «Прогноз постоянный, потому что сложные модели не улучшили CV».
6. Показать test RMSE/MAE/R² и сказать: «Это качество модели на отложенной выборке, а не неопределённость этого одного числа».
7. Завершить: «Приложение — учебная демонстрация; практическое решение требует испытаний».

## Демонстрация предупреждения об экстраполяции

Выбрать один заранее проверенный признак и значение чуть выше его `train_feature_ranges.max` из manifest. Не использовать бесконечность, NaN или физически абсурдное число. Показать, что приложение предупреждает о выходе за train-диапазон, но не выдаёт придуманную физическую границу. Затем вернуть медиану.

## Что делать при сбое

- Сообщение об отсутствии manifest: проверить наличие `models/model_manifest.json` в полном комплекте проекта.
- Сообщение об отсутствии artifact: проверить относительный путь в manifest и наличие joblib-файла.
- Порт 8501 занят: завершить старый контейнер или использовать `-p 127.0.0.1:8502:8501` и открыть `http://localhost:8502`.
- Контейнер не стартует: показать уже полностью выполненный notebook и evaluation-рисунки; не придумывать прогноз вручную.

## Запрещённые формулировки

- «Модель оптимизирует состав» — задача отношения не является оптимизацией.
- «R² — процент точности» — это неверно.
- «Выбросы были ошибками» — IQR определяет только кандидатов.
- «Модель пригодна для любых композитов» — внешняя применимость не подтверждена.
- «Это реальный новый образец» при использовании медиан формы — медианы являются демонстрационным вводом.
