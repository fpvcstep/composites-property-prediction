## Слайд 2. Зачем прогнозировать свойства — 0:35

«Лабораторные испытания композитов требуют образцов, оборудования и времени. Модель может дать предварительную учебную оценку и помочь понять, какой сигнал содержится в имеющейся таблице. Она не заменяет физическое испытание. В работе решаются две прямые задачи: прогноз модуля и прочности при растяжении. Отдельно исследуется восстановление отношения матрица–наполнитель, но это не задача поиска оптимального состава».

## Слайд 3. Данные и INNER JOIN — 0:40

«Исходные данные находятся в двух таблицах XLSX. После проверки индекса таблицы объединяются операцией INNER JOIN с отношением one-to-one. В результате получено 1023 наблюдения и 13 полей; 17 строк второй таблицы не имеют пары и в объединение не входят. Пропусков и полных дубликатов нет. Для каждой прямой задачи используются 11 признаков, для задачи отношения — 12 остальных полей. Происхождение наблюдений, группы материалов и часть единиц в паспорте не раскрыты, поэтому их смысл не додумывается».

## Слайд 4. Протокол без утечек — 0:50

«Данные один раз разделены на 716 обучающих и 307 тестовых строк. Тест до окончательной оценки не участвует ни в анализе, ни в настройке. Внутри train заранее сохранены десять KFold-разбиений. На каждом фолде scaler, IQR-границы и параметры модели обучаются только на fit-части, а ошибка считается на validation-части. GridSearch сравнивает варианты по среднему CV RMSE. После этого семейство и конфигурация фиксируются в отчёте, и только затем test открывается один раз. Такой порядок не позволяет информации из test улучшить выбор модели».

## Слайд 5. Разведочный анализ — 0:40

«Разведочный анализ выполнен только на 716 обучающих строках. Пропусков не обнаружено, а угол нашивки принимает значения 0 и 90 градусов. Максимальная абсолютная корреляция Pearson равна примерно 0,119. Низкая парная связь не исключает нелинейных взаимодействий, но не доказывает причинность. Правило полутора межквартильных размахов отмечает статистических кандидатов на выбросы, а решение об их удалении проверяется кросс-валидацией».

## Слайд 6. Предобработка — 0:40

«Служебный индекс исключён из признаков, угол кодируется значением ноль или один. IQR-фильтр проверен внутри кросс-валидации: на полном обучающем наборе он оставлял 663 строки для обеих прямых задач и 655 для обратной регрессии отношения. Для выбранных моделей меньшую среднюю RMSE дал вариант без удаления. Границы фильтра и параметры масштабирования оценивались только на обучающей части каждого фолда; проверочные и отложенные строки не удалялись».

## Слайд 7. Сравниваемые модели — 0:40

«Для модуля и прочности сравниваются константная модель, Ridge, Random Forest, Gradient Boosting и SVR. Для отношения используется MLP с архитектурой 12–32–16–1. Главный критерий выбора — средняя RMSE по десяти фолдам; дополнительно сохраняются MAE и R². Одинаковый протокол позволяет оценивать сложные методы относительно простого прогноза среднего».

## Слайд 8. Выбор по перекрёстной проверке — 0:45

«Для модуля минимальную среднюю RMSE получила константная модель: 3,087 ГПа. Для прочности выбран Gradient Boosting с RMSE 490,209 МПа, однако он лучше константной модели только в четырёх из десяти фолдов. Средняя парная разность составляет плюс 0,291 МПа при стандартном отклонении 8,345 МПа, поэтому статистически и практически значимое превосходство не установлено. MLP отношения также хуже константной модели: 0,935 против 0,906».

## Слайд 9. Результаты для модуля — 0:45

«Для модуля при растяжении минимальную среднюю CV RMSE получил DummyRegressor, который выдаёт среднее обучающей цели. На 307 отложенных строках его RMSE равна 3,178 ГПа, MAE 2,556 ГПа, а R² минус 0,016. В знаменателе R² используется среднее оцениваемой выборки, тогда как модель хранит среднее обучающей части, поэтому отрицательное значение возможно. Среди испытанных семейств и сеток полезного улучшения для модуля не получено».

## Слайд 10. Результаты для прочности — 0:55

«Для прочности Gradient Boosting дал минимальную среднюю CV RMSE, но был лучше константной модели только в четырёх из десяти фолдов; средняя парная разность равна 0,291 МПа при стандартном отклонении 8,345 МПа. На отложенной части его RMSE равна 471,410 МПа против 473,288 у константной модели, а R² равен 0,008. MAE выбранной модели — 380,152 МПа против 378,984 МПа у ориентира. Выбор сделан заранее по CV RMSE, поэтому статистически и практически значимое превосходство не заявляется».

## Слайд 11. MLP для отношения — 0:50

«Для отдельной задачи отношения матрица–наполнитель обучена MLP 12–32–16–1 с alpha 0,01. Выбран вариант без удаления IQR-кандидатов; обучение завершилось после 76 эпох, восстановлены веса эпохи 35. На отложенной части RMSE равна 0,944, MAE 0,777, R² минус 0,040; у константной модели RMSE 0,926. Модель оценивает отношение по полному профилю, включая заданные механические свойства. Это математическая трактовка рекомендации, но слабое качество, отсутствие причинности и физической проверки не позволяют рекомендовать рецептуру».

## Слайд 12. Интерпретация и ограничения — 0:45

«Пермутационная важность измеряет изменение RMSE после перестановки признака. Для константной модели модуля все важности нулевые, потому что её прогноз не использует признаки. Для модели прочности изменения ошибки невелики и имеют заметный разброс. Это характеристика поведения модели, а не причинный эффект. Из-за неизвестных партий, групп и происхождения наблюдений вывод относится только к случайно отложенным строкам данной таблицы».
