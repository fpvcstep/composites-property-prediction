# Прогнозирование свойств композиционных материалов

Композиционный материал состоит из нескольких компонентов. Матрица — связующее, которое удерживает компоненты вместе, а наполнитель — второй компонент, например волокна, которые могут усиливать материал. В проекте исследуются примеры из двух предоставленных таблиц; точные типы компонентов и происхождение строк в исходных данных не указаны.

Работа решает три задачи:

1. по 11 характеристикам состава и изготовления оценивает модуль упругости при растяжении — жёсткость в области, где материал восстанавливает форму после снятия нагрузки; чем выше модуль, тем меньше удлинение при одинаковом напряжении;
2. по тем же 11 характеристикам оценивает прочность при растяжении — предельное напряжение перед разрушением; напряжение означает нагрузку, делённую на площадь поперечного сечения;
3. по 12 остальным полям, включая известные модуль и прочность, восстанавливает записанное соотношение матрицы и наполнителя с помощью нейронной сети.

Третья задача оценивает существующий столбец. Она не подбирает рецептуру и не обещает получить материал с заданными свойствами. Все три результата имеют низкую точность, поэтому приложение служит демонстрацией построенного процесса, а прогнозы не заменяют лабораторные испытания.

## Основные результаты

Ошибки ниже получены на тестовой выборке из 307 строк, которая не использовалась при выборе моделей. RMSE сильнее реагирует на крупные ошибки, MAE показывает средний модуль ошибки, а R² сравнивает модель с прогнозом среднего и не является процентом точности.

| Задача | Выбранная модель | RMSE | MAE | R² | Вывод |
|---|---|---:|---:|---:|---|
| Модуль упругости при растяжении | прогноз среднего | 3,178 ГПа | 2,556 ГПа | −0,016 | Испытанные сложные модели не улучшили базовый прогноз |
| Прочность при растяжении | градиентный бустинг | 471,410 МПа | 380,152 МПа | 0,008 | Улучшение RMSE мало; практическая точность не подтверждена |
| Соотношение матрица–наполнитель | MLP | 0,944 | 0,777 | −0,040 | Нейросеть хуже прогноза среднего |

Для прочности RMSE градиентного бустинга немного ниже, чем у прогноза среднего (473,288 МПа), но MAE хуже: 380,152 против 378,984 МПа. Модель была выбрана заранее по средней RMSE перекрёстной проверки, а не по тестовой выборке.

## Последовательность исследования

1. **Постановка задачи.** Строка таблицы рассматривается как один предоставленный пример, столбец — как его характеристика. Среди входов есть плотность, количество отвердителя, содержание эпоксидных групп, расход смолы, угол, шаг и плотность нашивки.
2. **Описание используемых методов.** Для прямых задач сравниваются прогноз среднего и четыре метода: гребневая регрессия (Ridge) складывает вклады признаков с подобранными коэффициентами, случайный лес усредняет ответы деревьев решений, градиентный бустинг поэтапно исправляет ошибки предыдущих деревьев, а регрессия на опорных векторах (SVR) ищет зависимость с допустимой зоной отклонения. Для отношения сравниваются многослойный персептрон (MLP) и прогноз среднего.
3. **Разведочный анализ данных.** До анализа 1023 строки разделены на обучающую выборку из 716 строк и тестовую из 307. Распределения, диаграммы размаха, попарные зависимости, средние, медианы, корреляции и пропуски изучались только на 716 обучающих строках.
4. **Предобработка данных.** `data/raw/X_bp.xlsx` и `data/raw/X_nup.xlsx` соединены по совпадающему исходному индексу. Получены 1023 строки и 13 содержательных полей; 17 строк второй таблицы не имели пары. Пропусков, бесконечностей и полных дубликатов нет. Проверены варианты со всеми строками и с фильтрацией необычных значений по межквартильному размаху (IQR).
5. **Разработка и обучение модели.** Заранее выделены обучающая выборка из 716 строк и тестовая выборка из 307 строк. На обучающей выборке выполнен поиск гиперпараметров по сетке с десятикратной перекрёстной проверкой. Все обучаемые преобразования вычисляются внутри каждого повтора, чтобы сведения из проверяемой части не влияли на обучение.
6. **Тестирование модели.** Модели обучены на обучающей выборке с выбранным способом обработки, затем один раз проверены на тестовой. Для итоговых выбранных моделей использован вариант без удаления строк. Результаты приведены выше и подробно разобраны в РПЗ и `docs/results.md`.
7. **Нейронная сеть для соотношения матрица–наполнитель.** Сеть 12–32–16–1 уступила прогнозу среднего и не используется как рекомендация состава.
8. **Приложение и воспроизводимость.** Streamlit-приложение показывает два прямых прогноза и предупреждает о выходе входов за диапазоны обучающей таблицы. Команды полного воспроизведения приведены ниже.

## Структура проекта

## Полное воспроизведение в Docker

Требуются Docker Desktop и режим Linux containers. Команды выполняются из корня проекта. Переменная `PYTHONDONTWRITEBYTECODE=1` и отключённый pytest cache не создают служебные кэши в каталоге проекта. Контейнер собирается по Dockerfile; изменяемый тег базового образа и незакреплённая версия pip ограничивают побитовую воспроизводимость среды при будущей сборке.

```powershell
docker build -t composites-thesis:local .

docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python -m pytest -q -p no:cacheprovider
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python scripts/audit_data.py
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python scripts/prepare_data.py
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python scripts/run_eda.py
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python scripts/train_models.py
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -v "${PWD}:/workspace" -w /workspace composites-thesis:local python scripts/evaluate_models.py
```

`evaluate_models.py` выполняют после выбора по обучающей части: он один раз оценивает зафиксированные артефакты на отложенной выборке и формирует `reports/evaluation`, `figures/evaluation` и `models/model_manifest.json`.

Повторный `train_models.py` выполняет полный поиск гиперпараметров на обучающей части и итоговое обучение выбранных конфигураций; это может занимать несколько минут. Для изучения используйте опубликованные результаты и notebook с выключенным флагом `RETRAIN_ALL_MODELS`.

## Запуск без установки проекта в его каталог

Docker — рекомендуемый путь. Если нужен CPython 3.12, виртуальное окружение создаётся рядом с проектом, а импорт исходников задаётся через `PYTHONPATH`. Это не создаёт `.venv`, `egg-info` или bytecode внутри итогового каталога.

```powershell
$project = (Get-Location).Path
$venv = Join-Path (Split-Path -Parent $project) '.venv-composites'
py -3.12 -m venv $venv
& "$venv\Scripts\python.exe" -m pip install --upgrade pip
& "$venv\Scripts\python.exe" -m pip install -r "$project\requirements.lock.txt"
$env:PYTHONPATH = "$project\src"
$env:PYTHONDONTWRITEBYTECODE = '1'
& "$venv\Scripts\python.exe" -m pytest -q -p no:cacheprovider "$project\tests"
```

## Notebook

`notebooks/research.ipynb` читает опубликованные audit/EDA/modeling/evaluation-артефакты и поясняет каждый график. По умолчанию он не повторяет GridSearch. Выполнить notebook в контейнере и сохранить outputs можно без дополнительного служебного скрипта:

```powershell
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -e MPLBACKEND=Agg -v "${PWD}:/workspace" -w /workspace composites-thesis:local python -c "from pathlib import Path; import nbformat; from nbclient import NotebookClient; p=Path('notebooks/research.ipynb'); n=nbformat.read(p,as_version=4); NotebookClient(n,timeout=600,kernel_name='python3',resources={'metadata':{'path':'/workspace'}}).execute(); nbformat.write(n,p)"
```

## Streamlit-приложение

Приложение запускается из read-only bind mount:

```powershell
docker run --rm -e PYTHONDONTWRITEBYTECODE=1 -p 127.0.0.1:8501:8501 -v "${PWD}:/workspace:ro" -w /workspace composites-thesis:local streamlit run app/streamlit_app.py --server.address=0.0.0.0 --browser.gatherUsageStats=false
```

Откройте `http://localhost:8501`. Значения формы по умолчанию — медианы обучающей выборки, а не измеренный образец. Для содержательного прогноза введите фактические 11 характеристик. Выход за минимумы и максимумы обучающей выборки сопровождается предупреждением об экстраполяции. Приложение выдаёт модуль в ГПа и прочность в МПа; метрики тестовой выборки описывают модель в целом и не являются неопределённостью отдельного прогноза.

## Результаты

Выбор по обучающей выборке и перекрёстной проверке опубликован в `reports/modeling`, финальная оценка — в `reports/evaluation`. Метрики выбранных моделей на тестовой выборке:

| Задача | Модель | RMSE | MAE | R² |
|---|---|---:|---:|---:|
| Модуль упругости при растяжении | baseline | 3,178 ГПа | 2,556 ГПа | -0,016 |
| Прочность при растяжении | Gradient Boosting | 471,410 МПа | 380,152 МПа | 0,008 |
| Отношение матрица–наполнитель | MLP | 0,944 | 0,777 | -0,040 |

Для модуля испытанные сложные модели не улучшили константную модель. Для прочности RMSE Gradient Boosting на отложенной выборке равна 471,410 МПа против 473,288 МПа у константной модели, однако R² остаётся около нуля. MLP хуже константной модели: её RMSE равна 0,944 против 0,926. Отрицательный R² означает, что сумма квадратов ошибок превышает сумму квадратов отклонений от среднего целевой переменной оцениваемой выборки. Это возможно и для `DummyRegressor`, который использует среднее обучающей, а не отложенной выборки. Полученные результаты относятся только к испытанным моделям, сеткам и случайно отложенной части данной таблицы; они не подтверждают практическую точность.

## Ограничения

Неизвестны происхождение наблюдений, партии и серии, типы матрицы и наполнителя, а также смысл части единиц. Случайное разбиение оценивает качество на отложенных строках той же таблицы при данном разбиении; перенос на новые классы материалов не проверен. Прогнозы не заменяют лабораторные испытания.
